# 🤖 OMNI AI

## Omni-Agentic Intelligent Automation System

OMNI AI is an intelligent multi-agent AI platform designed to function as a centralized personal and technical AI assistant.

The platform uses **Grok AI** as its core intelligence and reasoning engine, **Python** for application logic, and **Streamlit** for the interactive web interface.

OMNI AI can analyze a user's request, identify the appropriate specialized AI agent, and generate an intelligent response through either **Demo Mode** or **Grok API Mode**.

---

## 🌟 Key Features

- 🧠 AI Orchestrator / Master Agent
- ⏰ Daily Reminder Agent
- ❤️ Health & Wellness Agent
- 📅 Calendar & Schedule Agent
- 📚 Learning & Education Agent
- 📝 Productivity & Task Management Agent
- 💰 Finance & Expense Management Agent
- 🌐 Information & Communication Agent
- 🤖 Robotics Agent
- 🚁 Drones & Autonomous Systems Agent
- 🎮 Demo Mode
- 🔑 Grok API Mode
- 💬 Interactive Streamlit chat interface
- 🔄 Automatic agent detection
- 🗂️ Session-based conversation history
- ☁️ Streamlit Community Cloud deployment support
- 🔐 Secure API-key configuration through Streamlit Secrets
- 🚫 No database required for the initial version
